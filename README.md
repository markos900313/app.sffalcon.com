# SFFALCON | Admin Panel

Private SaaS Dashboard for SFFALCON clients.

## 🚀 Technology Stack
- **Framework**: [Next.js 14](https://nextjs.org) (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Database & Auth**: Supabase
- **Integrations**: Evolution API (WhatsApp), Google Gemini (AI Agents).

## 🛠️ Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Environment Variables**:
   Create a `.env.local` file in the root directory and add the necessary keys (Supabase, Evolution API, Groq/Gemini, etc.).
   
   > [!IMPORTANT]
   > The `.env.local` file is automatically ignored by Git to protect sensitive keys. **Never** upload this file to the repository.

3. **Development Server**:
   ```bash
   npm run dev
   ```

4. **Access**:
   Open [http://localhost:3000](http://localhost:3000) to view the application.

## 📁 Key Features
- **Dashboard**: Real-time overview of business metrics.
- **Client Management**: CRM for tracking interactions and status.
- **AI Agents**: Automated chatbots powered by Gemini.
- **Finances**: Expense and income tracking with AI analysis.
- **Integrations**: Centralized settings for WhatsApp, Email, and AI.

## 🔒 Security
- All sensitive keys are stored in environment variables.
- The project follows Next.js security best practices for Server Components and Route Handlers.
- `.gitignore` is configured to prevent accidental leaks of local configuration files.
